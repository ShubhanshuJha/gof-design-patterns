# GoF Design Patterns in Java and Python

A practical, example-driven repository for learning all **23 Gang of Four (GoF) design patterns** in **Java and Python**. Each pattern is explained from first principles and implemented in both languages with clear examples, trade-offs, and exercises.

## Repository goals

- Understand the problem each design pattern solves.
- Learn the structure and collaboration of the participating objects.
- Compare object-oriented implementations in Java and Python.
- Recognize when a pattern is useful—and when it introduces unnecessary complexity.
- Build a reusable reference for interviews, system design, and day-to-day development.

### Behavioral

Chain of Responsibility · Command · Interpreter · Iterator · Mediator · Memento · Observer · State · Strategy · Template Method · Visitor

## Pattern directory structure

Every pattern follows the same structure:

```text
pattern-name/
├── README.md       # Concept, motivation, structure, trade-offs, and exercises
├── java/           # Java implementation
└── python/         # Python implementation
```

The Java and Python implementations will solve the same example problem wherever practical, making the language and design differences easy to compare.

## Learning format

Each pattern lesson will cover:

1. The problem and motivation
2. The pattern intent
3. Participants and collaboration
4. UML-style structure or sequence flow
5. Java implementation
6. Python implementation
7. Real-world use cases
8. Advantages and trade-offs
9. Related patterns
10. Exercises and interview questions
